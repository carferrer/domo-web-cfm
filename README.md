# Domo WEB

Catalogo publico de Home Assistant para la aplicacion distribuida mediante una imagen privada de GHCR.

Consulta [las instrucciones de migracion y uso](DOCS.md) antes de actualizar.

Disponible mediante Ingress (abrir Home Assistant por HTTPS) y por la URL HTTPS habitual.
Ambos accesos mantienen el login y OTP de la aplicacion.
El codigo PHP, la construccion y los scripts de arranque se mantienen en el repositorio privado.
